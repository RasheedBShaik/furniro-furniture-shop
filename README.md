
# 🛋️ Furniro — Furniture Shopping Website

A modern furniture shopping web application built with **React, TypeScript, and Vite**.

🌐 **Live Demo:** [Visit Furniro](https://furniro-furniture-shop.vercel.app/)

---

## 📌 Overview

Furniro is a furniture-shopping web project built with a modern React development stack and TypeScript for type safety.

## 🚀 Tech Stack

- React
- TypeScript
- Vite
- React Router
- Tailwind CSS
- Lucide React

## ⚙️ Getting Started

### Prerequisites

- Node.js
- npm
- Git (optional)

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/RasheedBShaik/furniro-furniture-shop.git
```

**2. Enter the project directory**

```bash
cd furniro-furniture-shop
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

### Production Build

```bash
npm run build
```

To preview the build:

```bash
npm run preview
```
