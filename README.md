Furniro — Furniture Shopping Website

A modern furniture shopping web application built with React, TypeScript, and Vite. This project provides a foundation for a clean, responsive furniture-shopping experience.

Live Demo: Visit Furniro

Overview

Furniro is a frontend web project focused on furniture shopping. It is built using a modern React development stack, with TypeScript for type safety and Vite for a fast development experience.

Tech Stack
React — Component-based user interfaces
TypeScript — Type-safe JavaScript development
Vite — Development server and build tooling
React Router — Client-side routing
Tailwind CSS — Utility-first styling
Lucide React — Icon library
Getting Started

Follow these steps to run the project locally.

Prerequisites
Node.js and npm
Git (optional, for cloning the repository)
Installation
Clone the repository:
bash
git clone https://github.com/RasheedBShaik/furniro-furniture-shop.git

Navigate to the project directory:
bash
cd furniro-furniture-shop

Install dependencies:
bash
npm install

Start the development server:
bash
npm run dev

Open the local URL displayed in your terminal.
Production Build

To create a production build, run:

bash
npm run build


To preview the production build locally, run:

bash
npm run preview
